# Domain docs

Where this repository keeps its vocabulary and decisions.

- **Glossary:** `GLOSSARY.md` <or the actual path>. Use its terms in issues,
  plans, test names and commit messages; do not drift to synonyms it rules out.
- **Decision records:** `docs/adr/NNNN-<slug>.md` <or the actual path>. Read
  the ones touching the area you work in. When a plan or change contradicts
  one, say so explicitly instead of overriding it silently.

If a file does not exist yet, proceed without it; create entries when a term or
decision is actually settled.
